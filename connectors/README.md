# A02 power connectors (Metal2 → Metal5)

Generated by `scripts/build_a02_power_connectors.py` from `A02.def (1)/A02/project_defs/A/A02_A.def`.

Same idea as ChipFoundry `vccd1_connection` / D10 `vss_conn`: padframe IO power is
**Metal2**; our core PDN is **Metal4/Metal5**. These cells bridge them.

| Cell | Net | Place (macro µm) | Size |
|------|-----|------------------|------|
| `vss_conn` | VSS (W12) | `0.0, 6.36` | 20.0 × (span of template VSS pins) |
| `vdd_conn` | VDD (W13) | `0.0, 106.36` | 20.0 × (span of template VDD pins) |

## D10-style user macro (recommended)

```bash
make build-a02-d10-style build-a02-power-connectors
make librelane-a02-macro-nodrc   # iterate
make librelane-a02-macro         # full flow (no skips)
```

Uses `src/a02/A02_A.v` + `librelane/floorplan/A02_A_full.def` + `MACROS` placement,
`LVS_CONNECT_BY_LABEL`, and a Metal5-only connector PDN grid in `pdn_cfg_core.tcl`.

## Rebuild

```bash
python3 scripts/build_a02_power_connectors.py
```

(No KLayout Python module required — pure-Python GDS fallback.)

## Legacy core-only harden

See `librelane/config_ai_byte_core.yaml` `MACROS` + `ai_byte_top.v` `(* keep *)` instances.

Then: `make librelane-core` (or `-nodrc` to iterate).

## Weld into existing `final_core` without full reharden

```bash
python3 scripts/weld_a02_power_connectors.py
```
